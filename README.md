# GitHub Final Project

A small static HTML/CSS/JavaScript assignment used for GitHub publishing practice. The page embeds a Bee Movie script gist and displays the current date with JavaScript.

## Features

- Static HTML page
- External gist embed
- Current date inserted into the page
- CSS styling

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
style.css
script.js
```

## What I Practiced

- Creating a small static site
- Linking CSS and JavaScript files
- Embedding external content
- Updating text content with JavaScript
- Publishing coursework with GitHub
